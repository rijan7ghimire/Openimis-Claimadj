# The ranking algorithm as a notebook

A mirror of `Week 5/ranking_notebook` inside the app repository, so the hosted app can link to it.

- `claim_ranking.py` — the app engine (`backend/engine/{existing.js, rules.js, store.js}`) ported line for line to Python. `python claim_ranking.py` prints the headline numbers for both synthetic books and reproduces the app exactly (474 flagged / 418 true on the training book, 386 / 193 on the validation book).
- `claim_ranking.ipynb` — executed notebook: dataset overview, the flowchart, the rule code, one claim followed through, flags and suspicion, precision@k against a random sample, parameter sweeps, a drop-one-rule ablation, the learning loop, the honest two-book evaluation, and an export step.
- `flowchart.py` — draws `figures/algorithm_flowchart.png`.
- `figures/` — the PNG figures and `results.json` the notebook writes. The app's **Algorithm** page (`frontend/public/algorithm/`) and the Week 5 slides show these same files.

The books are read from `../backend/data/claims.json` and `validation.json` (all synthetic; generated by `Week 3-4/synthetic_data/`).

```
pip install pandas numpy matplotlib jupyter
jupyter notebook claim_ranking.ipynb
```

After a change: re-run the notebook, then copy `figures/*` to `frontend/public/algorithm/` so the Algorithm page updates.
